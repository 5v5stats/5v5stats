Upload from the rendering PC

After a render, send the match here with one command:

python C:\cs2render\upload.py de_inferno_2026-11-05_02-31-19

Or render and upload in one go: python render.py match.dem --upload. Stats only (no clips, no CS2): python upload.py --demo match.dem. Add --public to make it public right away. Weekly 5v5stats update: python import5v5\sync.py. The same match uploaded again updates it (same link, same public/hidden setting). Server: {{ server }}; the upload token is in web\admin.env.

Upload a package by hand

A match package is the .zip made by python upload.py <match> --zip-only: stats, clips, thumbnails and profile pictures.
